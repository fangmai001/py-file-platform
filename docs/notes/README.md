# 筆記索引

這裡放**要留存、其他人也需要看得到**的專案筆記——例如部署踩雷紀錄、環境設定備忘、某個決定的來龍去脈。

完整規則（哪些東西該放這裡、哪些不該）寫在 README 的
「[文件與筆記](../../README.md#-文件與筆記-documentation-and-notes)」一節，這裡不重複。

只講最低限度的兩件事：

- **不要放密鑰、LDAP／SMTP 的實際設定值，或內部主機名稱。** 這是 public repo。那類內容請寫進
  `*.local.md`（已被 `.gitignore` 排除）。
- **隨手速記也不要放這裡。** `docs/` 的變更一樣要走 feature branch + PR，而且會跑滿整套 CI。

## 命名慣例

檔名使用 `kebab-case.md`（例如 `offline-delivery-gotchas.md`），檔案第一行是 `#` 標題。新增筆記時，
順手在下方清單補一行。
